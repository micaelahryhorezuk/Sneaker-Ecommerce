# Sneaker - Tienda Online de Zapatillas

## Descripción del proyecto

**Sneaker** es un proyecto de desarrollo de una plataforma de comercio electrónico para la venta de zapatillas.

Actualmente, la tienda realiza sus ventas mediante redes sociales y WhatsApp, lo que dificulta la atención inmediata de los clientes, el seguimiento de los pedidos y el control del stock.

El proyecto propone desarrollar una tienda online que permita a los clientes consultar productos, seleccionar sus variantes y realizar compras de manera autónoma.

## Objetivo

Digitalizar y optimizar el proceso de ventas de Sneaker mediante una plataforma web que mejore la experiencia de compra, facilite la administración de productos y pedidos, y permita ampliar el alcance de la tienda a nivel nacional.

## Funcionalidades previstas

### Clientes
- Registro e inicio de sesión.
- Consulta del catálogo de zapatillas.
- Búsqueda y filtrado de productos.
- Visualización de detalles, talles, colores y disponibilidad.
- Carrito de compras.
- Proceso de checkout y pago online.
- Envíos a domicilio.
- Consulta del historial de compras.
- Seguimiento de pedidos.
- Lista de productos favoritos.
- Chatbot de asistencia.

### Administradores
- Administración de productos y categorías.
- Control y actualización del stock.
- Gestión de pedidos.
- Consulta de pagos.
- Seguimiento de envíos.

## Metodología de trabajo

El proyecto se organiza utilizando **Scrum**, con una planificación de ocho Sprints de dos semanas y una etapa final de cierre.

Para priorizar los requisitos se utiliza el método **MoSCoW**:

- **Must:** funcionalidades imprescindibles.
- **Should:** funcionalidades importantes.
- **Could:** funcionalidades deseables.
- **Won't:** funcionalidades fuera del alcance actual.

Las tareas se administran mediante GitHub Projects, donde se registran sus estados, prioridades, responsables, estimaciones e iteraciones.
